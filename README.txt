Finance Calculator PWA

วิธีติดตั้งบน Android:
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ finance-pwa ไปยังบริการโฮสต์เว็บ HTTPS เช่น GitHub Pages, Netlify หรือ Cloudflare Pages โดยรักษาโครงสร้างไฟล์เดิม
3. เปิด URL ของเว็บไซต์ที่เผยแพร่ผ่าน Google Chrome บน Android
4. แตะเมนู ⋮ แล้วเลือก 'ติดตั้งแอป' หรือ 'เพิ่มไปยังหน้าจอหลัก' (ชื่อเมนูอาจต่างกันตาม Chrome)
5. เปิดแอปจากไอคอนบนหน้าจอ หลังเข้าใช้งานครั้งแรกและโหลดไฟล์ครบแล้ว แอปสามารถทำงานออฟไลน์ได้

หมายเหตุ: การเปิด index.html ตรงจากไฟล์ในเครื่องไม่ใช่วิธีติดตั้ง PWA; ต้องใช้ HTTPS หรือ localhost เพื่อให้ service worker ทำงาน
ข้อมูลคำนวณไม่ถูกส่งไปยังเซิร์ฟเวอร์ สูตรทั้งหมดทำงานภายในเบราว์เซอร์
